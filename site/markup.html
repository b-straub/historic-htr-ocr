The output format

The model writes what is on the page, as it is laid out — plain text, one line per written line, plus a few paired marks for what a plain transcription loses. The training ground truth is written in the same format.

Lines and blocks

  • One output line per written line; a blank line between blocks (paragraphs, margin notes, address, footer).
  • Page reading order: main text first, then margin notes, insertions placed apart, footnotes, catchwords (below).
  • A line-end hyphen only where the ink has one, written -.

Inline marks

Each mark has its own opening and closing character, so nesting stays readable.

  • Per line. A mark opens and closes on the same line (or table cell); a span across lines is closed at the line end and opened again on the next line.
  • Nesting. Different marks nest properly: ⟦ab⌈c⌉⟧. The same mark does not nest in itself — except the double underline, two underline pairs directly inside each other.
  • No clashes. None of the mark characters occurs as real ink in the training corpora (0 of 33,690 pages), so a mark is always a mark.

What is kept as written

  • Spelling, abbreviations (u., Hr., d. J.), punctuation, capitalisation; nothing is expanded or normalised.
  • The nasal bar over m / n (U+0305, e.g. m̅).
  • Long s: kept as the training editions wrote it — most write s, two keep ſ. The model therefore writes ſ only occasionally (in hands like those sources); normalise ſ → s if you need uniform text.

What is deliberately left plain

  • Passage strike-outs. A whole passage crossed out (a paragraph, a region) is written as plain text — striking a passage is an editing step, not a reading step. Word- and line-level strikes are marked.
  • A replacement written in the line. When a struck word is followed directly by its replacement in the same line, the replacement is plain: ⟦bereits⟧ schon. Only a replacement written elsewhere (above, below, in the margin) carries ⟨ ⟩.
  • An insertion that starts with a reference sign (⌈+⌉) is not wrapped in ⟨ ⟩: the sign already says it was moved.
  • Bold, italic, letter-spacing, colour, changes of hand or script (Latin words inside Kurrent are just text), overwritten under-layers (only the final letters are given), editors' additions, expansions, notes.

Tables

  • One line per table row; cells separated by a TAB. An empty cell is nothing between two TABs.
  • A line break inside a cell is ↵; a paragraph break inside a cell is ↵↵.
  • A cell spanning several columns is one field; a cell spanning several rows writes its text in its top row.
  • A table of one column is written as plain lines. Inline marks work inside cells as anywhere else.

Humboldt	Berlin	1856

Reading order vs. scholarly editions

Editions (TEI) follow the logic of the text; this model follows the layout of the page. Where they differ, the ground truth was rebuilt in page order:

  • margin notes and insertions written apart from their anchor come as their own block, not inline
  • marks by a later hand (archive stamps, pencil numbering) are their own blocks
  • footnotes and catchwords stand at the foot of the page as written
  • two-column drafts are read left column, then right column
  • tables are rows, not the edition's prose

Compare the output with an edition's text only after accounting for this: plain CER against an edition's reading text overstates the error.

Converting the output

convert_output.py (shipped with the model on Hugging Face) turns the output into plain TEI P5, or into a self-contained HTML viewer of that TEI — the examples are made with it:

python convert_output.py page.txt --to tei  --status raw > page.xml
python convert_output.py page.txt --to html --status raw > page.html

The TEI is a diplomatic transcription in page order, with no <choice>, <expan> or editorial apparatus. A mark the model runs across a line break is closed and reopened per line, and noted; any other malformed mark is reported with its line number and nothing is written.
